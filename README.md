# MotoNav

Android / iOS 手机配合 ESP32-S3 圆屏的导航项目。当前公开源码：**Android 8.3.26**、**红绿灯读秒实验 8.3.26-fusion.19.2**、**iOS 0.15.0**、**1.75 固件 7.12.9-junction.11（通用开机画面）**。1.85B 保留 7.12.3-185B，禁止混刷。Fresh 不包含在本次发布。

**1.75 固件成品下载：[v7.12.9-junction.11 Release](https://github.com/zyn950929/MotoNav/releases/tag/firmware-v7.12.9-junction.11)**，含 Windows 一键烧录 ZIP、独立镜像、固件源码和 SHA256。仅适用微雪 1.75，不能用于 1.85B。

[本轮完整更新说明与验证范围](docs/RELEASE-2026-10-25.md) · [安卓红绿灯实验版说明](experiments/traffic-lights/README.md) · [iOS 功能与构建说明](docs/RELEASE-IOS-0.15.0.md)

**安卓红绿灯读秒属于实验功能，不保证一直有效。** 上游服务、账号权限、地区和路口覆盖、网络、后台限制及路线匹配变化都可能使它停止、缺失或不可用。无数据或核对不符时不补造读秒。任何导航图标和读秒都不能代替道路上的实际交通信号。

iOS 0.15.0 本轮仅公开源码，**尚未经过 Xcode 编译、没有新版 IPA、未做 iPhone 真机验证**；不包含红绿灯读秒。历史 Release、IPA 仍保留原版本，请勿把旧包当作本次更新。构建方式与平台限制见上述说明。

**本项目借助 AI 辅助开发，由个人进行需求设计、设备验证和迭代。仅供个人非商业使用与学习交流，禁止未经许可的商业使用及转售。**

## 本次更新（2026-10-25）

### 安卓原版 8.3.26

- **摩托车规划不用先进入网页**：直接在 App 输入起点、目的地和途经点，后台读取高德网页摩托车路线，在 App 内预览并选择方案。遇到登录或验证时仍需本人完成，登录会话保存在本机。
- **新增自行车路线规划**：使用高德 SDK 骑行接口，支持真实与模拟导航；不加入电瓶车规划。
- **改善蓝牙连接与重连**：优先接续系统已有连接，增加服务发现、通知订阅和连接超时处理，修复部分“手机蓝牙已连接，App 却一直显示正在连接”的情况。
- 保留五个独立设置页面、首页巡航入口、四种地图风格、地图加载状态、轨迹记录／GPX 导出、常用目的地、区级天气及提前到达修复。

### 安卓红绿灯读秒实验版

- **小屏右侧显示路口读秒**：靠近匹配路口约 300 米内，竖排显示左转、直行、右转图标和实际秒数。缺少右转数据时显示灰色图标／灰色实心圆，不显示数字，避免误认为已确认绿灯。
- **导航中可以返回修改设置**：收起导航画面后，定位、语音和圆屏传输继续，再通过“返回导航”恢复画面。
- **网页摩托车导航支持路口信息匹配**：核对道路、方向与路口位置后再显示对应数据；补回红绿灯地图标记和电子眼／测速／拍照点位。
- 改进读秒卡片闪烁和过期数据清理，处理重复导航播报问题。
- **红绿灯读秒不保证一直有效**：上游服务、接口、账号、地区、路口覆盖、网络、定位和系统后台限制变化都可能使其失效；不保证每个路口或每个方向都有数据，无路线巡航读秒仍待实际道路验证。必须以现场交通信号为准。

普通版与读秒实验版源码分开存放，根目录“一键打包”构建普通版。实验版有额外构建输入要求，使用前请阅读 [实验版开发说明](experiments/traffic-lights/README.md)。

## 支持的硬件

1. **M5Stack Stopwatch（本仓库独立维护并适配）**
   - **硬件规格**：ESP32-S3，1.43 英寸 466×466 圆形 AMOLED（CO5300 QSPI）、CST820B 触控、M5PM1 电源管理、M5IOE1 扩展。
   - **源码位置**：`firmware/boards/stopwatch/MotoNav`
   - **适配特性**：
     - **伴侣模式（Avatar）**：主界面从上往下滑动进入呆萌灵动的伴侣表情互动；支持触控眨眼、视线跟随手指、滑动切换表情、长按生气；支持六轴 IMU 体感注视与摇晃晕眩表情、震动马达反馈；长按 A+B 键随时返回主界面；待机 2 分钟无连接自动进入伴侣模式，5 分钟无互动休眠关机；接电待机永不休眠；导航中 1 分钟无操作自动返回导航，导航过程中永不休眠；后台保持 BLE 广播，App 连接成功自动跳回主程序。
     - **特别致谢**：伴侣表情核心引擎与动画算法基于开源项目 [m5stack-stopwatch-avatar](https://github.com/Trentct/m5stack-stopwatch-avatar) 移植与二次开发，感谢原作者 [Trentct](https://github.com/Trentct) 的优秀开源工作！
     - **原生极速图形驱动**：复用同款 CO5300 QSPI 硬件 DMA 刷屏管线，466×466 原生点对点无损高帧率渲染。
     - **物理按键 A/B 联动换页**：骑行戴手套时操作更灵敏——面对屏幕左侧 A 键切到【音乐】（从左滑入）、右侧 B 键切到【天气】（从右滑入）；在天气/音乐页按任意按键平滑返回主页（带 250ms 防抖与动画防干扰）。
     - **赛博朋克风倾角与 G 值仪表**：内置 BMI270 六轴运动传感器，提供实时骑行压弯倾角、G-FORCE 加速度 HUD 与极值重置。
     - **物理按键深睡与唤醒**：无操作自动关机后，按任意物理按键（EXT1 唤醒源）即可重新唤醒开机。
     - **电量平稳管理**：基于 M5PM1 硬件采样并引入 7:1 软件低通滤波，告别电量跳动，原生支持充电闪电动画与低电提醒。
     - **一键出厂固件合并**：提供 `python tools/merge_firmware.py`，全自动编译并合并 bootloader、partitions、boot_app0 与主固件，生成适用于 **M5Burner** 从 `0x0000` 烧录的一键线刷包。
2. **Waveshare ESP32-S3-Touch-AMOLED-1.75（上游原生支持）**
   - 466×466 圆屏，固件位于 `firmware/boards/175/MotoNav`。

正式使用说明以 1.75 英寸板型为准。仓库原有 `firmware/boards/185b` 同步提供 7.12.3-185B 实验移植源码，360×360、三种面板初始化可编译，尚无本次实物验证；1.75 的外接电源自动关机例外未移植到 1.85B。

## 功能

地图、路线、转向提醒、车速、行程环、巡航、音乐控制和品牌开机动画；保留摩托车、驾车、自行车的路线分享处理。高德网页无法还原原路线时，按界面提示处理，不保证所有分享链接都能还原。

iPhone 新增圆屏 BLE HID 媒体按键，可向当前播放器发送播放/暂停和上一首/下一首，面向 QQ 音乐等播放器使用。导航与媒体按键共用同一 BLE 设备；HID 不读取歌名或确认播放状态。需要系统 HID 配对，QQ 音乐响应及锁屏行为尚待实机验证，详见 [配对与使用说明](docs/BLE-HID.md)。

## Windows 一键打包

1. 下载仓库 ZIP 并完整解压到较短的本地路径。
2. 双击根目录“一键打包.bat”。不需要 Android Studio。
3. 首次需要联网下载 JDK、Android SDK、Gradle 和依赖；SDK 许可由官方工具提示，阅读后自行决定是否接受。
4. 成功后 output/MotoNav-personal.apk 是安装包，output/Application-info.txt 包含生成的包名和签名 SHA1。

首次打包自动生成专属应用包名与签名。源码命名空间 com.example.motonav 与实际安装包 applicationId 可以不同。

**更新前必须备份 android/personal.properties 和整个 android/keystore 文件夹。新版解压后先复制回这两项，再打包，才能沿用包名、证书和地图绑定信息。不要把生成后的个人工程或证书公开上传。**

本仓库不包含编译工具、依赖缓存、APK、个人签名或地图天气凭据。国内网络访问部分官方下载站点可能需要额外的网络配置。

已有环境可执行：

```powershell
.\Build-Personal.ps1 -JavaPath 'D:\Tools\jdk-17' -SdkPath 'D:\Tools\android-sdk' -GradlePath 'D:\Tools\gradle\bin\gradle.bat'
```

已缓存所需依赖时可追加 -Offline。

## Mac 双击烧录

本机已安装 Arduino CLI / ESP32 Core 3.3.10 和 esptool 5.3.0。连接微雪 1.75 英寸圆屏的 USB 数据线，在 Finder 中双击根目录 [一键烧录固件.command](一键烧录固件.command)。脚本校验生成镜像的 SHA-256 和应用偏移，只有一个 USB 串口时自动选择，多个串口时要求选择。

默认写入 `0x10000` 的应用升级镜像，不执行整片擦除，适用于已有相同 16 MB / app3M_fat9M_16MB 分区的 MotoNav。首次完整安装可运行 `./一键烧录固件.command --full`，需输入 INSTALL 确认。脚本只支持本仓库的 1.75 英寸板型。

`./一键烧录固件.command --check` 仅检查工具、固件和串口，不写入设备。固件镜像与清单位于 `firmware/dist/175/panel0/`；源码仓库不提交这些生成文件，缺少时需先构建并生成清单。HID 配对步骤见 [说明](docs/BLE-HID.md)。

## 固件构建

iOS 与 Android 共用一份圆屏固件，源码位于 `firmware/boards/175/MotoNav`，第三方库位于 `firmware/libraries`。手机端 APK 与 IPA 分开发布，详见 [通用固件说明](firmware/README.md)。

使用 Arduino CLI，安装 Espressif ESP32 Arduino Core 3.3.10，然后执行：

```powershell
.\firmware\build.ps1 -Board 175
```

可用 -CliPath、-ConfigFile 指定自己的 Arduino CLI 和配置。输出在 firmware/dist 中。已有相同板型及分区的 MotoNav 使用 app_0x10000 升级镜像；首次安装使用 full_0x0 完整镜像。完整刷写可能覆盖原程序和设置，请先备份。
