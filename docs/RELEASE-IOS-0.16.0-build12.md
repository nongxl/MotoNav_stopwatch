# iOS 0.16.0 Build12 更新说明

2026-10-31。同步最新 iOS 源码、图标、来源说明及配套 1.75 pages.5 固件源码。本轮不修改安卓功能代码。

## UI 来源

本次 UI 参考移植并适配 **[coolcoolmanman（@coolcoolmanman-design）的 MotoNav](https://github.com/coolcoolmanman-design/MotoNav)**，参考 **0.15.21-tpms** 的 [c01d6db1a323e91d0b0210b796d9bb6a0cd7bd0f](https://github.com/coolcoolmanman-design/MotoNav/tree/c01d6db1a323e91d0b0210b796d9bb6a0cd7bd0f)。

参考内容为导航/轨迹/圆屏/我的四栏目、语义配色、玻璃导航栏、设备卡、连接动画及轨迹布局。感谢原作者的设计与实现。项目在既有 0.16.0 功能上进行适配，胎压、音乐封面和对方其他固件扩展不在本次移植范围。详见 [来源说明](../ios/UI-SOURCE-NOTICE.md)。

## 功能与修正

选路、最多三个有序途经点、加油站搜索、收藏和最多 20 条摩托车规划历史已接入新界面；模拟速度统一为 60/100/120 km/h。修正自行车扩展请求与真实路径解析，保留真实转向数据，不捏造缺失分段。

地图处理修正浅色地块误分类导致的黑纹，并按风格隔离缓存。实际记录曾显示地图已取到，但 112,461 字节的建筑图从排队到末片应答约 32.25 秒，127,289 字节约 35.50 秒；因此修正蓝牙缓冲等待与确认流程，新区域优先基础图，提前准备楼块，并按实际覆盖时间和带宽补发。用户随后反馈底图正常。

针对之后的楼块反复出现/消失，App 增加同区域基础图降级保护；配套 pages.5 在既有双缓冲内按世界坐标继承重叠区域已知楼块，新道路、水面和新楼块优先。不额外增加地图蓝牙字节数；新增操作发生在收图解码时，每帧绘图代码保持原样。未准备的新区域仍需后续数据。

保留时间/时区同步、初始重试、周期校时，以及 HID/AMS 控制与歌曲信息重取修正。天气仍使用用户自行配置的和风天气。地图衔接记录支持恢复旧有效文件、分享和保存到“文件”，修复首次导出空白。

**Build12 仅更换新图标并递增构建号，其 Swift 功能代码与 Build11 相同。**

## 更新顺序

1. 1.75 圆屏升级到 **7.12.10-pages.5**，已有同板型同分区 MotoNav 选应用升级 `0x10000` 保留配对和设置。详见[固件说明](RELEASE-FIRMWARE-7.12.10-pages.5.md)。
2. 使用自己的 Apple 账号签名 IPA，保留 MotoNavShare 扩展；沿用原签名身份和实际安装的 Bundle ID 覆盖。
3. App 中确认版本/构建号，保持原地图风格和楼块开关后重新连接，同路线模拟观察底图与楼块。

源码和 Actions 构建产物见 [iOS 使用说明](../ios/README.md)。仓库不提交个人 Key、天气 Host、Cookie、签名证书、原始用户诊断文件或个人打包配置。
