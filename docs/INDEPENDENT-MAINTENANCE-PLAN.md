# MotoNav Stopwatch 独立维护与演进规划路线图

> **文档状态**：已归档规划（供后续开发查阅）  
> **制定日期**：2026-10-26  
> **维护主体**：MotoNav Stopwatch 社区独立分支  

---

## 1. 背景与项目新定位

上游项目原作者（`zyn950929/MotoNav`）已于 2026 年 10 月发布最终版本（Android 8.3.26 / 1.75 固件 7.12.9-junction.11）并宣布停止后续更新。

本项目（**MotoNav_stopwatch**）原作为针对 M5Stack Stopwatch 硬件的下游适配分支，自此正式转变为**完全独立维护的开源项目**。新定位为：
- **以 M5Stack Stopwatch 为核心第一公民**：充分发挥其 1.43 英寸 466×466 圆形 AMOLED、双实体按键、BMI270 运动传感器、RTC 离线时钟和振动马达等硬件优势，打造体验极致的摩托车/骑行智能仪表。
- **向下兼顾跨平台互通**：保持与主流 Android / iOS MotoNav App 协议的高效兼容，同时拓展独立特色的骑行与交互生态。

---

## 2. 核心架构收拢规划

### 2.1 分支策略与版本线
- **主分支提升**：将当前的 `feat/board-m5stopwatch` 合并提升为默认的 `main` 分支，统一日常开发、PR 与 Release 发布。
- **上游归档**：历史 `upstream/main` 作为 `upstream-archive` 冻结备份，用于追溯基础功能历史实现。
- **Release 语义化版本**：从 `v8.0.0` 起建立独立的版本发布体系（如 `v8.0.0-stopwatch.1`）。

### 2.2 Android 端双工程融合
- **现状痛点**：目前上游遗留了 `android/`（基础版）与 `experiments/traffic-lights/`（读秒实验版）两套工程，依赖配置与打包入口割裂。
- **规划方案**：
  1. 将红绿灯读秒与关键点校验作为**实验性功能开关**无缝合并入 `android/` 主工程；
  2. 统一根目录的 `一键打包.bat`，一键生成包含完整能力的单一正式版 APK；
  3. 保留摩托车原生规划、免网页选路、自行车支持以及蓝牙连接改进。

### 2.3 Stopwatch 固件模块化拆解
- **现状痛点**：当前固件逻辑集中在 1 万多行的 `MotoNav.ino` 单文件中，维护难度与修改风险高。
- **规划方案**：借鉴上游 1.75 固件的模块化解耦模式，重构为清晰的子系统目录：
  - `src/connectivity/`：BLE 通信、数据包分片重组、认证与心跳；
  - `src/display/`：CO5300 QSPI DMA 双缓冲刷屏管线；
  - `src/map/`：矢量/栅格地图解码、视差旋转与雷达渐暗特效；
  - `src/pages/`：大箭头导航、小地图、倾角仪表、天气、音乐控制与来电页面；
  - `src/avatar/`：伴侣模式引擎、表情骨骼动画与手势/体感交互；
  - `src/power/`：M5PM1 电量滤波采样与休眠关机调度。

## 3. 固件特色功能演进

### 3.1 伴侣模式（Avatar）深化
- **多角色支持**：利用已预留的 `CompanionRole` 接口，支持切换不同个性的表情形象（如呆萌柴犬、像素猫咪等）；
- **动态换肤与交互拓展**：支持左右滑动手势或手机 App 蓝牙一键配置伴侣外观，丰富触控与六轴晃动晕眩彩蛋。

### 3.2 骑行运动遥测（Telemetry）看板
- **压弯与极值统计**：基于板载 BMI270 陀螺仪与加速度计，在现有倾角仪表基础上增加“单次骑行运动摘要”页面：
  - 本次骑行最大左/右压弯倾角（角度保持记忆）；
  - 最大急加速 / 急减速 G-FORCE 峰值；
  - 骑行总耗时、平均车速与最高极速记录；
  - 提供实体按键一键重置当前统计。

### 3.3 离线表盘与精准 RTC 时钟
- 充分利用 Stopwatch 内置的 **RX8130CE RTC 时钟芯片**：
  - 在未连接手机或无导航的纯待机状态下，提供高颜值常驻时钟表盘（极简指针、数字电子表等）；
  - 彻底摆脱“必须连手机才能看时间”的限制，兼作桌面骑行时钟或日常智能手表。

## 4. 手机端中枢维护与体验打磨

### 4.1 高德与天气 API 长效自愈
- 密切跟踪高德开放平台与和风天气接口规范变动；
- 增加本地缓存与接口降级容灾，杜绝因外部服务抖动导致页面一直处于 `LOADING`。

### 4.2 骑行场景下的前台保活与蓝牙自愈
- **前台保活指引**：针对各主流 Android 厂商（MIUI/澎湃OS、ColorOS、OriginOS、HarmonyOS）完善电池无限制与自启动指引；
- **自愈重连机制**：针对进出隧道断网、短暂离车断连等场景，优化自动静默重连，无需掏出手机重新点开 App。

### 4.3 iOS 端自动化构建
- 保持与固件通信协议同步；
- 配置 GitHub Actions 自动化编译工作流，推送时自动生成未签名 IPA 附件，方便使用 Sideloadly 或巨魔一键安装。
