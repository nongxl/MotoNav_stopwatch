## 公开内容与依赖来源

- `android/`：MotoNav 读秒实验完整 App 源码，包含接收、匹配、导航、蓝牙、后台协调和界面。
- `car-integration-deltas.json`：相对于配套补丁 APK 的三个集成文件增量，带修改前后 SHA256，避免误改其他版本；不包含该第三方软件的完整源码。
- `build-fusion.py`、`prepare-merge.py`、`compile-manifest.py`、`pack.py`、`resource_table.py`：本项目的资源、Manifest 及本地库构建工具。
- `tests/`：灯状态、方向、输出时效、道路核对、关键点、信号灯与摄像头匹配回归。

数据来自用户提供的第三方高德 9.5.13 配套补丁 APK。补丁曾以 CameraLightInteract／巡航灯 smali 的形式提供；原始作者及许可信息没有在附件中完整给出，本项目不声称拥有该补丁或配套软件的著作权，也不把它们声明为本项目自有开源代码。此目录不包含第三方数据提供端 APK、完整反编译代码、原作者签名或任何个人 Key；请自行确认输入软件的使用及分发授权。高德 SDK 与服务仍适用服务商条款。

## 构建实验安装包（Windows）

准备 JDK 17、Python 3、Gradle 8.10.2、Android SDK 35／build-tools 35.0.0、apktool，以及你自行取得的配套已打补丁 9.5.13 APK。

仅对以下输入做过集成：SHA256 `f0fe164279a6d60bd83d926a32d47f335f044faf9c0d37564b49655e95db0141`。脚本对其他输入直接拒绝，不能把不同输入版本当成兼容输入。

在本目录执行，路径按自己电脑修改：

```powershell
python build-fusion.py --provider 'D:\Inputs\provider.apk' --apktool 'D:\Tools\apktool.jar' --gradle 'D:\Tools\gradle-8.10.2\bin\gradle.bat' --sdk 'D:\Android\Sdk' --java-home 'D:\Tools\jdk-17'
```

依赖已经缓存时可加 `--offline`。脚本会验证输入、隔离命名空间、应用集成增量、编译两个部分、校验资源／重复类、生成 APK，再用本机新生成的调试证书签名；不会安装手机、上传数据或发布仓库。

成品：`output/MotoNav-8.3.26-fusion.19.2.apk`。**`android` 单独编译得到的 APK 只是构建中间件，不能当最终实验安装包使用。** 最终包名是 `com.autonavi.amapauto`，版本字段保留运行依赖要求，MotoNav 页面显示实验版本。输出会打印真实证书 SHA1，用最终包名及该 SHA1 申请自己的高德 Android Key，再在 App 配置。私下保存 `android/.local/debug.keystore`，以后用同一证书更新；不要提交证书。当前入口使用开发签名，正式分发需自行管理发布证书。

如果手机上已有相同包名、不同签名的旧软件，无法直接覆盖；卸载会清除其登录、离线地图和设置，请先自行备份。普通手机版高德和普通 MotoNav 是不同包。

初次启动允许附近设备／蓝牙和必要通知、定位权限，再连接匹配固件的圆屏；读秒开关和必要初始化入口在 App 中。读秒期间需要保持必要的数据进程运行。后台耗电、锁屏定位与数据覆盖受手机系统及上游限制。
